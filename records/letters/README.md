# Family letters

This working collection contains five family letters from 1935 to 1987. Each PDF bundles images of the original with the prepared translation and, where available, a German transcription.

Page numbers refer to PDF pages, counted from 1. Letter IDs stay fixed when dates or names are corrected. The Markdown records reproduce the prepared text and retain its uncertain readings. The PDF preserves the page layout and typography.
